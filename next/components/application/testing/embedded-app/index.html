    Testing an embedded app

    On the embassy runtime, TestApp runs a device service's EmbeddedApp on the host, with every broker connected in process and the clock the app reads in the test's hands. The test hands the app function its brokers, as the device's task does, and drives the app with the same calls a tokio test makes: broker, settle, advance and shutdown. The app runs inside the test's own future, so a test is a plain #[test] that blocks on one future, and one TestApp runs at a time in a process.

    The harness is the test build's embassy-time driver: the clock starts at zero and moves only when the test moves it. embassy-time's own mock-driver is a second driver of the same clock, and a build links only one of the two.

    TestApp::start returns once the app is running. A broker that waits on the clock to connect, or a subscription that waits to open, is waited for: the clock moves from one armed deadline to the next, and a startup nothing wakes returns TestError::Stalled.

    shutdown lets the work the app holds run to its end: the clock moves from one armed deadline to the next until the app has stopped. A handler or a hook that waits on a timer finishes, the shutdown hooks run and every broker shuts down. Work that waits on something nothing wakes makes shutdown return TestError::Stalled, and an app that stopped on its own error returns it as TestError::Failed.

    What the harness adds​

    Out slot records​

    tb.out::<M>() opens the record of the Out slot marked M: every message a handler sent through it, with its destination and headers. It reads the same way as on tokio, as the out page describes. A slot publish is also recorded on its destination, so published::<T>(name) on the broker it went to sees it.

    Hooks​

    on_call and on_publish take the same async closures as on tokio. A hook runs inside the test's own future: the dispatch that recorded the event waits for it, and the step that drives the app polls it beside the app. A hook runs on the test's own thread, and a hook that waits on the clock finishes once the test advances it or shuts the app down. A hook on a destination the test itself publishes to runs in that publish, up to where it waits on the clock. A panic inside a hook, a failed assertion included, fails the publish, settle, advance or shutdown that ran it.

    A state the test builds​

    TestApp::with_state(app, build) starts the app with the state build returns in place of the one the app was built with: a value read from the board's flash, a driver of its hardware. The app function names its state in its type, EmbeddedApp<impl Mounts<State = Limits>>, so the test can build one. The harness connects every broker first, then calls build with the brokers, so brokers.broker::<B>() returns the connected form of the app's broker of type B, as on tokio. Everything else of startup runs as in TestApp::start.

    crates/ruststream-testing/tests/embedded.rs
    #[test]
    fn an_out_slot_publish_is_recorded_with_its_slot() -> Result<(), Box<dyn Error>> {
        block_on(async {
            let tb = TestApp::start(app(Bus::new())).await?;
            tb.broker::<Bus>()
                .message(&Sent(b"high"))
                .to("sensors/level")
                .publish()
                .await?;

            tb.out::<Alerts>().assert_called_once().with_raw(b"high");
            tb.shutdown().await?;
            Ok(())
        })
    }

    fn an_alarm_goes_through_its_slot() -> Result<(), Box<dyn Error>> {

                .await?;

            Ok(())
        })
    }

    crates/ruststream-testing/tests/embedded.rs
    #[test]
    fn a_slot_publish_hook_runs_in_the_publish_that_caused_it() -> Result<(), Box<dyn Error>> {
        block_on(async {
            let tb = TestApp::start(app(Bus::new())).await?;
            let hooked = Arc::new(AtomicUsize::new(0));
            let seen = Arc::clone(&hooked);
            tb.out::<Alerts>().on_publish(async move |alerts| {
                alerts.assert_called_once().with_raw(b"high");
                seen.fetch_add(1, Ordering::SeqCst);
            });

            tb.broker::<Bus>()
                .message(&Sent(b"high"))
                .to("sensors/level")
                .publish()
                .await?;
            assert_eq!(hooked.load(Ordering::SeqCst), 1);
            tb.shutdown().await?;
            Ok(())
        })
    }

    crates/ruststream-testing/tests/embedded.rs
    #[test]
    fn the_test_hands_the_app_its_state() -> Result<(), Box<dyn Error>> {
        block_on(async {
            let tb = TestApp::with_state(tank(Bus::new()), |brokers| Limits {
                alarm: 50,
                echo: Some(brokers.broker::<Bus>().publisher()),
            })
            .await?;
            tb.broker::<Bus>()
                .message(&Sent(b"\x64"))
                .to("tank/level")
                .publish()
                .await?;

            tb.out::<Alerts>().assert_called_once().with_raw(b"\x64");
            tb.broker::<Bus>()
                .published::<()>("tank/echo")
                .assert_called_once()
                .with_raw(b"\x64");
            tb.shutdown().await?;
            Ok(())
        })
    }
    crates/ruststream-testing/tests/embedded_manual.rs
    #[test]
    fn the_board_alarms_from_the_tests_limit() -> Result<(), Box<dyn Error>> {
        block_on(async {
            let tb = TestApp::start(tank(Bus::new())).await?;
            tb.broker::<Bus>()
                .message(&Sent(b"\x64"))
                .to("tank/level")
                .publish()
                .await?;
            tb.out::<Alerts>().assert_not_called();
            tb.shutdown().await?;

            let tb = TestApp::with_state(tank(Bus::new()), |_brokers| Limits { alarm: 50 }).await?;
            tb.broker::<Bus>()
                .message(&Sent(b"\x64"))
                .to("tank/level")
                .publish()
                .await?;
            tb.out::<Alerts>().assert_called_once();
            tb.shutdown().await?;
            Ok(())
        })
    }
