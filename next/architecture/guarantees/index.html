    Guarantees

    Mistakes that do not compile, and the error the compiler prints for each.

    A mistake the compiler can see is a compile error, not a check at startup or on each message. A check per message would cost every delivery, and a check at startup finds the mistake only where the service first runs. Each error names the type or the step at fault.

    Each row is a reply, transform, codec, publisher capability, dispatch, publish and typed header rule, in that order. A setting fixed once on a mount chain cannot be fixed again, and a capability the broker lacks is a missing method or an unmet bound.

    The lifecycle is typed too: a broker that is not connected has no method to subscribe or publish with, and a closed one has been consumed.
