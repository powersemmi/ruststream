# Устройство

Ядро не знает ни одного брокера: крейт брокера реализует его трейты и хранит все настройки своего
брокера.

<Diagram name="design" words={words} />

Ядро не зависит ни от одного клиента брокера. Обязательных трейтов три: жизненный цикл
соединения, подписчик в виде `Stream` доставок и издатель. Пакеты, транзакции, запрос с ответом,
перемотка и значения, которые доставка уже несёт, оформлены трейтами совместимости. Брокер
реализует их, только если их умеет его клиент.

Словарь брокера живёт в его крейте. Там описаны формы подписки, политики издателей, настройки
отдельного сообщения и шаги монтирования, которые читают настройки цепочки. В ядре нет ни
настроек конкретного брокера, ни значений по умолчанию для них.

Кодек - это тип: [кодек](../components/subscribers/codecs/index.md), названный при монтировании,
или кодек по умолчанию, который выбирает включённая фича. Без фичи кодека значения по умолчанию
нет, и монтирование, которому кодек нужен, не компилируется.

Трейты, рантайм и каждый необязательный слой - отдельные крейты, а `ruststream` реэкспортирует их
под одним набором путей. Слои разделяет компилятор: крейт контракта, `ruststream-core`, не зависит
ни от одного другого крейта фреймворка. Он собирается с `#![no_std]` и требует только
распределителя памяти, поэтому от него может зависеть устройство; `ruststream` включает его фичу
`std` на каждой целевой платформе с операционной системой. Тело доставки (декодирование, middleware, обработчик, ответ, подтверждение)
находится в `ruststream-runtime` и не привязано ни к одному исполнителю. Оно обобщено по часам
среды выполнения и по ожиданию остановки приложения. `ruststream-runtime-tokio` исполняет его на
tokio и отвечает за то, что относится к tokio: жизненный цикл приложения, запуск задач, пулы
обработчиков, выделенные потоки и сигналы. Код сервиса, которому нужно подождать, вызывает
`ruststream::time::sleep`. Этот вызов спит по часам приложения, поэтому тестовый стенд сдвигает
его вместе со всеми остальными таймерами. Необязательный слой включается фичей cargo крейта
`ruststream`: [брокер в памяти](../components/memory/index.md), AsyncAPI, метрики,
журналирование, OpenTelemetry, [тестирование](../components/application/testing/index.md) и
командная строка. Фичи только добавляют возможности и не меняют поведение друг друга.
