# Путь

Этапы, через которые проходит одна доставка от потока брокера до подтверждения, в том порядке,
в каком их выполняет рантайм.

<Diagram name="path" words={words} />

[Подписка](../components/subscribers/subscription-source.md) и издатель ответа определяются один
раз, при старте приложения, по подключённому брокеру. На этом пути ничто не ищет подписку или
издателя заново для каждого сообщения.

[Слои приёма](../components/subscribers/middleware/layer.md) охватывают декодирование, поэтому
слой видит доставку, даже если её содержимое не декодируется. Такое содержимое не доходит до
обработчика: её судьбу решает [политика отказов](../components/subscribers/failure-policy.md).

Обработчик без ответа подтверждает доставку сразу после своего тела. Обработчик, который вернул
исход с ошибкой, ответ не публикует. Если ответ не удалось опубликовать, доставка уходит на
повтор, и запрос не теряется.

[Ответ](../components/subscribers/publishing/replies.md) уходит туда, куда велит его тип.
Издателю, который только читает байты, рантайм одалживает собственный буфер цикла, и ответ
ничего не выделяет. Издатель, который байты сохраняет, получает свой буфер.
