# Навыки для агентов

В репозитории лежат навыки для ИИ-агентов, которые пишут код. Навык - это руководство, которое
агент загружает, когда оно нужно задаче. С ним агент пишет код тем путём, который рекомендует
фреймворк.
В Claude Code навыки ставятся двумя командами:

```text
/plugin marketplace add powersemmi/ruststream
/plugin install ruststream@ruststream
```

Плагин приносит пять навыков.
Агент выбирает навык по его описанию, поэтому просьба о сервисе на RustStream загрузит нужный
навык и без его имени.

| Навык | Когда агент его берёт |
|---|---|
| `ruststream` | пишет сервис: обработчики, приложение, ответы, публикацию, повторы, состояние, кодеки |
| `ruststream-testing` | тестирует сервис через `TestApp` |
| `ruststream-without-macros` | собирает сервис без фичи `macros` |
| `ruststream-broker` | пишет крейт брокера |
| `ruststream-core` | вносит изменения в репозиторий ядра |

## Другие агенты

Каждый навык - это каталог с файлом `SKILL.md` и справочными страницами в
[`.agents/skills/`](https://github.com/powersemmi/ruststream/tree/main/.agents/skills)
репозитория.
Cursor и Codex читают навыки из каталога `.agents/skills/` того проекта, в котором работают.
Чтобы агент видел навыки в вашем сервисе, скопируйте нужные каталоги в этот каталог своего
проекта или в каталог навыков, который читает ваш агент.

## Совпадение версий

Навыки описывают фреймворк той ревизии, из которой взяты.
Ставьте их из той же линейки выпусков, что и `ruststream`, от которого зависит ваш сервис.
Навык - это руководство, а не проверка: о результате по-прежнему судят компилятор и тесты.
