# Руководства

Руководства ведут от пустого крейта к работающему сервису на RustStream.

- [Установка](getting-started/installation.md): крейт, его фичи cargo и крейт брокера.
- [Быстрый старт](getting-started/quickstart.md): работающий сервис из шаблона `cargo generate`.
- [Учебник](getting-started/tutorial.md): сервис заказов с типом сообщения, обработчиком, ответом
  и роутером на брокере в памяти.
- [Брокеры](../brokers/index.md): крейты брокеров и перевод сервиса на другой брокер.
