# 指南

指南带你从一个空 crate 走到一个运行中的 RustStream 服务。

- [安装](getting-started/installation.md)：crate、它的 cargo feature 以及 Broker crate。
- [快速上手](getting-started/quickstart.md)：用 `cargo generate` 生成并运行的服务。
- [教程](getting-started/tutorial.md)：一个订单服务，包含消息类型、处理器、回复和路由器，运行在内存
  Broker 上。
- [智能体技能](getting-started/agent-skills.md)：让编码智能体按推荐方式编写服务、测试和 Broker crate 的技能。
- [逐步构建一个服务](build-a-service/index.md)：同一个商店服务逐章扩展，从第一个订阅者一直到联网的
  Broker。
- [Broker](../brokers/index.md)：各个 Broker crate，以及如何把服务迁移到另一个 Broker。
