# Транзакционный outbox { #transactional-outbox }

Опубликовать событие и записать строку, которую оно описывает, - две операции, и падение между ними
оставляет систему в противоречивом состоянии: заказ записан, а события нет, или событие ушло по
заказу, который откатился. Outbox закрывает этот зазор: событие становится частью записи, а к брокеру
уезжает уже потом.

Паттерн не привязан к HTTP - он нужен везде, где публикация должна сходиться с записью в базу. Пример
ниже гоняет его из axum-эндпоинта, самого частого случая, а полный компилируемый исходник лежит в
[`examples/http_outbox.rs`](https://github.com/powersemmi/ruststream/blob/main/examples/http_outbox.rs):

```text
cargo run --example http_outbox --features macros,memory,json
```

## Событие пишется рядом с записью { #recording-the-event-beside-the-write }

Вместо публикации на пути запроса эндпоинт атомарно записывает событие рядом с бизнес-записью. Дальше
записанные события переносит в брокер relay:

```rust
--8<-- "examples/http_outbox.rs:event"
```

```rust
--8<-- "examples/http_outbox.rs:store"
```

Эндпоинт пишет только в хранилище. Сохранить заказ и поставить его событие в очередь - один атомарный
шаг, и никакой ввод-вывод с брокером не может уронить или подвесить ответ:

```rust
--8<-- "examples/http_outbox.rs:endpoint"
```

## Слив outbox в брокер { #draining-the-outbox }

Фоновая задача сливает outbox в брокер. Строка удаляется только после успешной публикации, поэтому
недоступность брокера события задерживает, а не теряет; падение между публикацией и удалением
приведёт к повторной публикации строки после перезапуска. Потребители, соответственно, получают
доставку at-least-once - обычный контракт outbox - и разбираются с дубликатами так же, как с
повторными доставками от самого брокера:

```rust
--8<-- "examples/http_outbox.rs:relay"
```

С настоящей базой `Store` - это таблица плюс таблица `outbox`, которые пишутся в одной
SQL-транзакции, а relay читает строки `outbox` в порядке вставки, публикует их и удаляет. Всё
остальное остаётся как показано: брокер, публикатор и подписчик не знают, что outbox вообще
существует.
