# RustStream

**RustStream** подписывает сервис на Rust на потоки событий и публикует в них, не привязывая сервис
к одному брокеру сообщений. Ядро - это трейты и рантайм с роутером; вместе с ним поставляются
кодеки, генерация AsyncAPI, метрики Prometheus и набор проверок `conformance` для авторов брокеров.

Фреймворк определяют два архитектурных обязательства:

1. **Полноценный интерфейс для сторонних брокеров.** В ядре лежат только трейты и типы, ни одной
   зависимости от брокеров. Каждый брокер - самостоятельный крейт, а соблюдение контракта проверяет
   набор `conformance`.
2. **Специфичная для брокера конфигурация остаётся в крейтах брокеров.** Ядро не несёт ни настроек,
   ни умолчаний, завязанных на конкретный брокер. Свой `Config` есть у каждого крейта брокера,
   поэтому изменение в апстриме задевает один крейт брокера, а не фреймворк.

```rust
--8<-- "examples/quickstart.rs"
```

`#[ruststream::app]` генерирует `main`, поэтому `cargo run -- run` запускает сервис, а
`cargo run -- asyncapi gen` печатает его AsyncAPI-документ - без единой строчки шаблонного кода
рантайма.

## Принципы дизайна

- **Полностью асинхронный, на tokio.** В публичной поверхности нет блокирующих API.
- **Обобщённое ядро, никакого `dyn` в контракте.** Ассоциированные типы и нативный
  `async fn in trait`; стирание типов, где оно сервису нужно, живёт в рантайме, а не в контракте.
- **Подписчики - это `Stream`, а не колбэки.** Обратное давление достаётся бесплатно, а удобство
  колбэков надстроено сверху, в рантайме.
- **Ack потребляет `self`.** Сделать ack дважды нельзя - за этим следит компилятор.
- **Трейты-возможности для необязательной функциональности** (`BatchSubscriber`,
  `TransactionalPublisher`, `RequestReply`, `Partitioned`, `Seekable`) - их никогда не втягивают в
  обязательный интерфейс.

## Что входит в этот репозиторий

Этот сайт документирует `ruststream` - чистое Rust-ядро (без PyO3, без конкретных брокеров).
Конкретные брокеры (NATS, Kafka, RabbitMQ, Redis, MQTT) живут в собственных крейтах и берут
`ruststream` с crates.io. Python-биндинги лежат в репозитории
[`ruststream-py`](https://github.com/powersemmi/ruststream-py).

Справочник по Rust API опубликован на [docs.rs](https://docs.rs/ruststream) - см.
[Справочник API](reference.md).
